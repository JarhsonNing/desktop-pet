# 剪切板历史与文件中转站

桌宠多批文件投递、逐文件选择与 Windows「此电脑」文件箱见 [FILEBOX.md](FILEBOX.md)。文件箱首版仅展示，不从资源管理器写回内容库。

## 使用

面板左栏或托盘打开「剪切板」「中转站」，也可使用 `--settings-page clipboard|transfer`。两个页面提供搜索、类型筛选、收藏和详情；按住 Ctrl（macOS 为 Command）点击记录可多选，批量复制、另存、收藏或删除。

| 内容 | 查看 | 取用 |
| --- | --- | --- |
| 文本、链接 | 完整纯文本 | 复制文字；拖入编辑器，或作为 UTF-8 `.txt` 文件拖出 |
| 图片 | 图片预览和尺寸 | 复制图片；拖出 PNG 文件及原生图片表示 |
| 文件、文件夹 | 名称、大小、目录信息；历史显示原路径 | 复制文件、另存到、以复制方式拖出，保留目录层级 |
| 邮件附件、虚拟文件 | 接收进度、落地后的文件 | 接收成功后按普通文件取用 |

目标应用决定接收哪种表示。点击图片缩略图可查看大图。拖出前先准备真实路径，大文件或文件夹需要点击「准备拖出」；准备过程中可以取消。拖动详情页中的「拖动这里，带到其他应用」进入系统拖放，记录不会被移走。另存到会拒绝覆盖已有同名文件，错误显示在面板中。目录详情显示前 500 项，导出始终保留完整目录。

## 剪切板

启动后监听新复制的通用文本、图片和文件列表，不导入系统已有历史；面板关闭仍记录，退出停止。顶部显示正在记录、已暂停或访问受限，暂停期间不补录。重新复制历史会忽略本程序的剪切板写入，避免循环；相同内容再次复制会更新原记录时间并置顶，保留收藏状态。

文本同时保留可用 HTML/RTF，详情只显示纯文本，不执行 HTML。遵守来源的敏感／不记录标记；剪切板占用只有限重试，权限拒绝显示原因。没有通用数据表示的私有对象无法收纳。

文本和图片存完整内容；文件历史只记录名称与原路径。原文件失效时提示「原文件已不存在」。需要长期保存文件时，点击「收纳到中转站」创建独立副本。

默认保留 30 天与最近 500 条非收藏记录，任一条件达到即清理；收藏不参与。偏好设置可以调整天数、条数、记录开关。清空历史保留收藏及中转内容；选择记录后删除可手动删除收藏。

## 中转站

将本地文件、多文件、文件夹、文字、图片、链接或系统附件拖到宠物上，每次拖入形成一组。也可在面板添加文件／文件夹或粘贴当前剪切板。接收期间宠物暂停走动；结束后出现提示气泡，点击打开中转站并选择新记录，不自动弹面板。

主动收纳均保存独立副本，原文件不移动、不删除。成功项目保留，失败或取消项目列出原因；中转内容持续保存直到手动删除。符号链接和 Windows 重解析点不会递归跟随，以免越出目录或循环复制。普通 ZIP 也作为文件收纳；加载皮肤请使用「皮肤」页的专用区域。

Windows 接收 OLE 文件描述符和内容流，并在拖放仍有效时读取数据；支持源应用的异步数据对象。macOS 接收系统文件承诺并落地。应用只提供私有对象、来源文件失效或附件无法读取时，会显示失败原因。

浏览器明确提供图片／文件数据时优先使用实际数据；提供下载信息时，可下载 HTTP/HTTPS 资源。普通网页链接和剪切板 URL 只作文字记录。下载开关在偏好设置；关闭后保留链接。登录失败、返回登录网页或只有 `blob:` 地址时，保留来源和错误，可重新下载或把浏览器保存的实际文件拖入。不读取浏览器登录凭据，不上传内容。

## 保存位置与清理

使用本机应用数据目录，Windows 默认 `%LOCALAPPDATA%\JarhsonNing\Mochi\data`；macOS 使用 `directories::ProjectDirs` 对应的用户应用数据目录。开发时 `--data-dir PATH` 可指定隔离位置。

可在偏好设置中分别更换「中转站存储目录」和「Mochi 文件箱目录」，后台复制完成后立即生效，原目录保留。剪切板与中转站共用内容库，因此会一起迁移。自选路径保存于 `storage.json`；以下 `content/` 为默认位置，自选后该目录中的数据库、资源、附件接收和导出缓存均位于用户选择的位置。详见 [目录切换说明](FILEBOX.md#自定义存储目录)。

```text
config.json              记录开关、保留策略、空间限额、下载开关
content/index.sqlite     记录元数据、搜索内容、资源引用（SQLite WAL）
content/assets/          正文、原始图片和文件／目录副本，按内容哈希共享
content/incoming/        正在接收的原生附件
content/tmp/             未提交的复制与下载
content/exports/         向其他应用提供真实路径的临时副本
```

内容库默认上限 5 GiB，界面显示正文／图片／文件资产的用量；SQLite 元数据和临时导出另占磁盘。空间不足时先清理可淘汰的剪切板记录，不自动删除收藏或中转内容，仍不足则停止新增并提示清理。文件和下载在后台执行，临时保存后原子提交；共享资产按数据库引用释放，清空历史不会误删已收纳的内容。

导出缓存单独显示用量，超过 24 小时清理；仍被本进程拖放或系统剪切板引用的导出受保护，所有权丢失后释放。退出停止监听、取消未完成任务并保留完成的数据；重启标记上次中断的记录并清除临时文件。默认全部本地保存，无云同步、OCR、自动模拟粘贴或应用私有对象解析。

记录内容未经额外加密，与用户自己的文件一样依赖系统账户及磁盘保护。删除记录会释放未被其他记录引用的内容，不清空系统当前剪切板。
