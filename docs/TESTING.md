# 验收清单

## 自动化

`cargo test --locked` 覆盖：安全默认值、授权版本、设置迁移和限值、冷落升级、授权隐藏、倒计时归还、互动归还、安静 / 忙碌、日志容量、原子保存、进程锁、损坏恢复日志和透明区域命中。

`cargo run -- --simulate` 不创建窗口，不触碰桌面，验证互动状态流。CI 在 Windows x64、macOS Apple Silicon 与 Intel 编译、测试、lint，并创建可下载 ZIP。

`scripts/ci_smoke.py` 在隔离目录启动真实设置窗口、采集自身 framebuffer PNG，然后启动透明宠物窗口并验证自动退出。CI 将 JSON 结果和图片单独上传；三个托管平台均已通过原生启动验证，这一步作为阻断检查。如果运行器图形环境发生变化，需要检查报告中的 `passed` 和诊断信息，不能跳过失败。

Windows 托管运行器不保证提供 OpenGL 2.0 驱动。CI 在真实 Windows 二进制旁放置固定版本、校验 SHA-256 的 Mesa 软件渲染 DLL，使截图检查不依赖虚拟机显卡。软件渲染依赖只用于 CI，不随安装包分发；不能把此环境的性能当成用户机器的性能。

## 每个平台的人工 GUI 验收

- 首次启动有透明角色和中文面板；背景透明，没有窗口边框或任务栏占位。
- 左键、双击、拖拽、投喂、玩球、三档模式、安静、忙碌、归窝都符合界面说明。
- 托盘 / 菜单栏可用，面板能关闭并重新打开，主宠物不随面板关闭退出。
- 捣蛋默认禁用；切换“小恶魔”不会自动授权隐藏；确认框清楚说明平台影响。
- 光标追逐可开启 / 撤销，10 秒后结束，期间点击能穿透，不移动系统光标。
- 宠物透明角落不阻挡底下窗口；屏幕缩放和多屏切换不把宠物留在不可见区域。
- 面板关闭后做发布性能采样，不以 debug 构建代替。

## 真实隐藏验收（需操作者明确同意）

不要在工作中的桌面自动运行。特别是 macOS：先关闭进行中的 Finder 操作，再开启单独授权。

1. 保存原始桌面可见性，开启授权，点击一次体验。
2. 验证图标消失但文件没有变化，守护存在、恢复日志存在。
3. 验证倒计时自动归还。
4. 分别验证恢复按钮、快捷键、托盘、普通互动和正常退出归还。
5. 仅强杀宠物主进程，守护应尝试恢复。
6. 强杀全部相关进程后重新启动 / `--restore-desktop`，日志应驱动恢复。
7. 原先图标已隐藏时，体验应拒绝修改；恢复原始偏好键的存在性。
8. 撤销授权 / 安静 / 切到乖巧时停止当前隐藏。

系统操作自动化只使用虚拟后端，不擅自改变开发者的桌面。GUI 和真实系统行为需要分别记录，不能用单元测试通过代替实际平台验收。
