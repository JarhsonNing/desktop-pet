# 验收清单

## 自动化

`cargo test --locked --workspace` 覆盖：安全默认值、授权版本、设置迁移和限值、冷落升级、授权隐藏、倒计时归还、互动归还、安静 / 忙碌、日志容量、原子保存、进程锁、损坏恢复日志和透明区域命中。面板新增管道 JSON 的中文与二进制表示，以及静态皮肤预览测试。

退出回归测试使用虚拟桌面操作，验证所有行为停止、保存的授权设置不变、退出等待正在执行的隐藏后恢复、跳过排队的捣蛋、重复清理、对象销毁兜底，以及恢复失败的重试与错误返回。不会隐藏真实桌面图标。

皮肤测试覆盖默认角色轮廓和动画命中、目录 / `.mochi` / ZIP 往返、解包与不覆盖已有输出、PNG 帧透明命中、未知版本、错误恢复按钮布局、异常路径及资源限额。命令行皮肤操作验证不会启动宠物或创建桌面租约。

昵称回归测试验证旧 egui 输入法事件、字体覆盖和可绘制字形，以及清空编辑缓冲区、简繁体与扩展区汉字保存、16 字符截断。Tauri 实窗测试验证浏览器文本输入、中文昵称持久化和系统关闭窗口提交草稿；系统输入法候选窗口另作人工验收。Windows 新面板截图可用 `--settings-page home|preferences|journal|skin|clipboard|transfer --screenshot PATH --exit-after 12 --data-dir ISOLATED_DIRECTORY` 逐页采集。

内容库测试覆盖中文与多行全文搜索（含 `%_`）、去重置顶、收藏、保留策略、SQLite 重启、文件历史只保存路径、中转副本在原文件删除后仍可导出、同名目标不覆盖、目录层级与预览、部分失败、共享资源引用、空间不足和进行中资产保护。还使用本地 HTTP 测试服务验证成功下载、登录网页／401 拒收和下载取消，验证异常退出恢复与导出缓存的 24 小时清理和引用保护。服务工作线程测试验证多文件收纳完成数量与关闭。

Windows 原生格式测试直接构造 OLE 数据对象，覆盖 Unicode 路径／文本、DIB V5 透明像素、虚拟附件内容及异常路径、浏览器 DownloadURL／网址格式、图片优先于下载链接、图片加文件的拖出表示，以及独立剪切板监听窗口的启动和停止。自动测试不读写系统剪切板正文、不隐藏真实桌面图标；格式测试通过不代表所有第三方应用已兼容。

`cargo run -- --simulate` 不创建窗口，不触碰桌面，验证互动状态流。当前 CI 默认仅在 Windows x64 编译、测试、lint、运行 Tauri 实窗检查并创建可下载 ZIP；macOS 按要求暂缓，可通过手动入口 `include_macos` 开启。

`scripts/ci_smoke.py` 在隔离目录启动真实设置窗口、采集 PNG，然后启动透明宠物窗口并验证自动退出。Windows 使用 Tauri / WebView2 CapturePreview；macOS 目前明确使用 `--legacy-panel`，不代表新面板通过验收。CI 将 JSON 结果和图片单独上传。如果运行器图形环境发生变化，需要检查 `passed` 和诊断信息，不能跳过失败。

Windows 托管运行器不保证提供 OpenGL 2.0 驱动。CI 在真实 Windows 二进制旁放置固定版本、校验 SHA-256 的 Mesa 软件渲染 DLL，使截图检查不依赖虚拟机显卡。软件渲染依赖只用于 CI，不随安装包分发；不能把此环境的性能当成用户机器的性能。

## 每个平台的人工 GUI 验收

- 首次启动有透明角色和中文面板；背景透明，没有窗口边框或任务栏占位。
- 六个设置页面的侧边导航、卡片、文本框、开关和按钮样式一致；缩小窗口后内容可滚动，底部恢复和退出按钮始终可见。
- 在「偏好设置」输入 `曦玥珩璟團團𠮷`，检查字形；清空后用中文输入法重新输入，确认候选输入不会被默认名打断。回车、失焦、切页、退出重启后昵称保持一致，超长昵称按 16 个字符保存。
- 左键、双击、拖拽、投喂、玩球、三档模式、安静、忙碌、归窝都符合界面说明。
- 托盘 / 菜单栏可用，面板能关闭并重新打开，主宠物不随面板关闭退出。
- 捣蛋默认禁用；切换“小恶魔”不会自动授权隐藏；确认框清楚说明平台影响。
- 光标追逐可开启 / 撤销，10 秒后结束，期间点击能穿透，不移动系统光标。
- 宠物透明角落不阻挡底下窗口；屏幕缩放和多屏切换不把宠物留在不可见区域。
- 面板关闭后做发布性能采样，不以 debug 构建代替。
- 在「皮肤」页加载 `Skins/blue.mochi` 和 `Skins/png.mochi`，确认宠物与预览同步、透明区域穿透、状态和气泡正常；重新加载目录、恢复默认和重启后的选择均生效。

## 剪切板与跨应用拖放的人工验收

1. 使用隔离 `--data-dir`，复制中文多行文字、链接、截图、多个文件；关闭面板后继续复制，再打开查看。暂停后复制不记录，恢复不补录；旧记录复制不新增循环记录。
2. 收藏、类型筛选、全文搜索、Ctrl／Command 多选、删除和清空；重启确认记录及收藏保留。复制的文件显示原路径，删除原文件后明确显示失效。
3. 拖入多文件、文件夹、同名文件及普通 ZIP，确认进入中转站。删除或移动原文件后副本仍可取回；皮肤加载仅走皮肤页专用区域。
4. 接收期间停止走动和拎起；结束出现可点击气泡，不自动打开面板，点击选中新记录。检查透明穿透和普通宠物交互。
5. Windows 邮件附件、浏览器图片与下载对象，macOS 邮件附件及系统文件承诺，分别确认实际内容落地。私有对象、无权限、下载失败、登录限制和 `blob:` 地址需有明确结果；成功项不随其他失败项丢失。
6. 大文件复制／下载／附件接收显示进度并可取消，空间不足不自动删除收藏与中转；强制中断后重启显示中断并清理临时数据。
7. 从详情的原生拖动入口分别拖到 Explorer／Finder、文本编辑器、浏览器上传区域和聊天应用；验证文字、图片、文件／文件夹、跨应用 COPY 和目录层级。取消拖出仍保留记录；不能用面板内拖动代替。
8. 验证复制及另存到，同名目标拒绝覆盖，清空历史不删除已收纳副本；确认退出停止监听、取消未完成保存并恢复既有桌面捣蛋状态。

## 真实隐藏验收（需操作者明确同意）

不要在工作中的桌面自动运行。特别是 macOS：先关闭进行中的 Finder 操作，再开启单独授权。

1. 保存原始桌面可见性，开启授权，点击一次体验。
2. 验证图标消失但文件没有变化，守护存在、恢复日志存在。
3. 验证倒计时自动归还。
4. 分别验证恢复按钮、快捷键、托盘、普通互动和正常退出归还。
5. 仅强杀宠物主进程，守护应尝试恢复。
6. 强杀全部相关进程后重新启动 / `--restore-desktop`，日志应驱动恢复。
7. 原先图标已隐藏时，体验应拒绝修改；恢复原始偏好键的存在性。
8. 撤销授权 / 安静 / 切到乖巧时停止当前隐藏。

系统操作自动化只使用虚拟后端，不擅自改变开发者的桌面。GUI 和真实系统行为需要分别记录，不能用单元测试通过代替实际平台验收。
