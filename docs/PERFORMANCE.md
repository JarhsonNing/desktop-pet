# 性能目标与测量

## 设计预算（不是保证值）

面板关闭、没有互动、单宠物的发布构建：平均 CPU 目标低于一个逻辑核的 1%，常驻内存目标小于 100 MiB。活跃动画 / 面板交互预算可以高于待机。不同系统、GPU 驱动和缩放比例必须单独实测。

- 矢量待机和发呆：2 FPS 定时重绘。
- 安静：1 FPS。
- 矢量玩耍、追逐、拖拽：12 FPS。
- 多帧 PNG：取基准与当前可见动画播放速度中的较高值，最高 30 FPS；单帧图片或重复同一路径的静态帧组不会提高预算。
- PNG 图片总像素预算提高至 12,582,912，以容纳更多中间帧；满预算解码 RGBA 约 48 MiB，纹理及程序本身另有开销。高帧数皮肤的内存目标不能套用下方默认角色历史测量。
- 节能：非安静活动限制为 4 FPS。
- 操作系统输入事件仍可触发额外重绘；以上不是输入事件总帧数的硬限制。
- 没有文件读写 / 偏好保存的逐帧循环，设置变更做短延迟合并。
- 悬停探测每 75ms 读取一个坐标，只在命中边界变化时重绘，动画帧率仍按状态控制。
- 恢复工作线程阻塞等待；守护只在隐藏期间启动，250ms 轮询，恢复后退出。
- 剪切板 Windows 采用系统通知，macOS 每 250ms 只比较变化计数，内容不变不读取正文。内容库工作线程空闲等待，文件复制、哈希、预览和下载在后台进行；复制流为 64 KiB，预览最大边长 900 像素。原生接收进度和内容服务消息会按需要唤醒界面。
- 搜索与列表使用元数据，预览按需要加载，关闭面板后继续捕获剪切板。大量正文、目录收纳和导出仍会占用额外内存与磁盘，不能套用下方旧版本的待机采样。
- Tauri 面板是按需子进程，未打开时没有 WebView。关闭窗口退出子进程并释放 WebView；前端快照轮询及原生面板事件泵也随之停止。主程序的宠物渲染和动画预算保持原有实现。

## macOS 测量

```sh
cargo build --release
sh scripts/profile_macos.sh target/release/desktop-pet idle
sh scripts/profile_macos.sh target/release/desktop-pet quiet
```

脚本使用临时数据目录，关闭面板，预热 8 秒，再每 3 秒采集 CPU 和 RSS，共 6 次。`ps %cpu` 是进程累计平均 CPU，不能当成每个 3 秒窗口的瞬时值；用于初步筛查。更精确的长期分析请用 Activity Monitor / Instruments，至少观察 5 分钟，记录主进程与按需守护的总资源。

## Windows 测量

发布构建运行后关掉面板，任务管理器观察 CPU / 工作集。PowerShell 可以采集进程 CPU 累积秒数，使用两次采样的差值 / 时间差 / 逻辑处理器数量计算整机归一化 CPU%。请记录 DPI、分辨率、CPU、系统版本和电源模式。

## 实测结果

2026-10-14，Apple M1 Pro / macOS 15.7.1 / 发布构建，面板关闭，使用上述脚本采集 6 次：

| 状态 | `ps` CPU 样本范围 | RSS 样本范围 |
| --- | --- | --- |
| 待机（含快速悬停探测） | 0.3%–1.3% | 83,696–83,840 KiB（约 81.9 MiB） |
| 安静（含快速悬停探测） | 0.0%–0.4% | 82,160 KiB（约 80.2 MiB） |

Apple Silicon 发布二进制约 5.0 MiB。CPU 样本算术平均分别约 0.53% 和 0.17%。以上是短时开发机采样，不代表所有设备的长期性能，也不隐去偶发峰值。上述默认角色在 Windows 和 Intel macOS 上的完整 CPU / 内存测量仍待补充。


2026-10-14，Windows 发布构建加载 174 帧的橘猫斗篷女孩补帧皮肤，打开设置面板六秒，采样工作集峰值 225.2 MiB；截图和退出成功。这是加载短测，包含设置面板，不代表关闭面板后的长期占用，也不证明平均 CPU 目标。报告见 `output/imagegen/orange-hood-girl/smooth-app-report.json`。

## Windows Tauri 迁移对照

2026-10-14，Windows 10 Pro 19045、Intel i7-12700（20 个逻辑处理器）、WebView2 154。发布构建使用默认矢量皮肤、乖巧模式、关闭走动与剪切板捕获，预热 7 秒，每阶段采样 30 秒。旧版为 `2c89a93` 的隔离构建，仅禁用托盘/热键以避免与正在运行的应用冲突；新版使用 `--no-shell`。

| 构建 / 阶段 | 工作集 MiB | 私有内存 MiB | 单核 CPU% | 整机归一化 CPU% | 面板/WebView 进程 |
| --- | ---: | ---: | ---: | ---: | --- |
| 迁移前，未打开面板 | 77.66 | 95.23 | 0.36 | 0.018 | 无 |
| Tauri 迁移后，未打开面板 | 78.19 | 95.20 | 1.72 | 0.086 | 无 |
| Tauri 迁移后，三次关闭面板 | 75.55 | 94.66 | 0.88 | 0.044 | 无 |

三次关闭均确认宠物存活、面板与 WebView2 进程全部退出，随后正常退出宠物。工作集与私有内存接近旧版；CPU 短测存在波动，不能据此保证与旧版逐数相等或长期满足单核 1% 目标。此前 12 秒样本中工作集从 77.80 增至 87.91 MiB，私有内存由 95.81 降至 95.05 MiB，也无残留面板进程；工作集页缓存变化不等于持续 WebView 占用。

174 帧橘猫斗篷女孩 PNG 皮肤也通过三次关闭检查。12 秒样本中，首次打开前工作集 184.26 MiB、私有内存 247.01 MiB；三次关闭后为 183.96 / 246.01 MiB，均无面板或 WebView 进程。整机归一化 CPU 分别为 0.039% / 0.084%；这是此皮肤的短测，不能套用默认矢量角色的内存预算。

测量需固定行为状态：调皮模式在约第 25 秒触发随机剧情，会改变帧率，不能把不同剧情阶段的采样作为严格对照。当前脚本因此统一使用乖巧模式。实窗交互和性能采样应顺序运行，避免共享 WebView 配置目录产生干扰。

```sh
python scripts/profile_tauri_windows.py --binary target/release/desktop-pet.exe --output .artifacts/tauri-perf --seconds 30
python scripts/profile_tauri_windows.py --binary target/release/desktop-pet.exe --output .artifacts/tauri-png --skin YOUR_SKIN.mochi
```

macOS 本次未运行检查；前面的 macOS 数据属于旧版 egui，不能作为新面板的验收结果。跨平台及长时间 CPU/GPU 采样仍需分别进行。
